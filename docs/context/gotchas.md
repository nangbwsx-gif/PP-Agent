# Gotchas

Traps someone already stepped on. This is the only append-only file in the
rulebook. Each entry is one line: a date, a title, the trap and the right
move, and the condition that retires it. The file holds 40 entries at most,
and anyone deletes an entry that no longer holds, in the PR that makes it
false. A gotcha that can become a test should become one.

- **[2026-09-13] The Google sign-in page says the flow completed before Waku has a token** — the browser page appears when Google hands back the one-time code, and Waku exchanges the code afterwards. An `InvalidClientError` after that page means Google rejected the client secret in `.waku/credentials.json`: download the OAuth client's JSON again. _Retire when: `waku connect google` reports a rejected secret in plain words._
- **[2026-09-13] `parseFloat` on a CSS custom property that holds `calc()` returns 0** — `--main-min` is a `calc()` expression, so reading it as a number silently breaks the dock's width limit. Resolve it by layout with a probe element, as `dockMax` in `js/main.js` does. _Retire when: `--main-min` holds a plain length._
- **[2026-09-13] Changing only the URL hash does not reload the dashboard's CSS or JS** — switching views with `#view` keeps the old stylesheets, so a CSS edit looks like it failed. Hard-reload, or change the query string. _Retire when: the dashboard serves assets with a content hash._
- **[2026-09-13] `text-overflow: ellipsis` needs a real child element** — a flex container's bare text is an anonymous flex item and cannot be ellipsized. Wrap the text in a span, as `uiBadge` does with `.badge-t`. _Retire when: badges stop being flex containers._
- **[2026-09-13] `oklab()` and `color()` values are on a 0–1 scale, not 0–255** — a contrast check that parses computed colours as 0–255 reports nonsense. Convert the colour through a canvas first. _Retire when: a contrast test exists in `evals/deterministic/`._
- **[2026-09-14] python-dotenv's `set_key` replaces a symlinked `.env` with a real file** — saving a setting from the dashboard inside a worktree detaches the linked `.env`. Check that `.env` is still a symlink before deleting a worktree. _Retire when: settings stop being written through `set_key`._
- **[2026-09-23] `server_close()` cannot hang on a daemon handler thread, and `daemon_threads = True` is what makes that true** — `ThreadingMixIn.server_close()` joins the handler threads it registered, but `_Threads.append()` returns early for daemon threads (CPython calls it "Joinable list of all non-daemon threads"). So the inherited `daemon_threads = True` on `DashboardServer` is load-bearing, not decoration: setting it to False was measured to drag a 0.9s shutdown out to 5.0s, the length of a stuck turn. A chat handler blocked in `host.ask()` is never what holds the exit. _Retire when: the dashboard stops using `ThreadingHTTPServer`._
- **[2026-09-23] Closing a SQLite connection a live thread is using splits a two-statement write** — `Host.stop()` waits for the running turn, and when it overruns its deadline it closes **nothing**: sqlite3 would raise `Cannot operate on a closed database` inside that thread, and `log_chat()` writes the user row and the assistant row as two separate statements, so the reply can go missing while the message stays. `stop()` returns False instead, and the OS reclaims the handle at exit. _Retire when: `Host.stop()` can cancel a running turn._
- **[2026-09-23] WeChat's iLink API reports a failed send as HTTP 200 with `errcode` and no `ret` field** — sending with a dead session answers `200 {"errcode": -14, "errmsg": "session timeout"}`. Every other endpoint on this API uses `{"err_msg": ..., "ret": N}`, so a checker that only reads `ret` sees nothing wrong and records the reply as delivered. `waku/gateway/wechat.py::_call` reads **both** fields; the unit tests that pin it fake `urlopen`, because a fake API object bypasses `_call` entirely. _Retire when: the iLink API documents one error envelope._
- **[2026-09-23] `ThreadingMixIn.server_close()` does not wait for daemon handler threads** — this is what lets Ctrl-C exit while a chat handler is mid-turn, and it works because `_Threads.append()` returns early when `thread.daemon` is set and `ThreadingHTTPServer` keeps `daemon_threads = True`. Flip that flag and a stuck turn drags a 0.9s shutdown out to the length of the turn; the ordering in `serve_until_signalled` (host first, server second) only softens the queued case. _Retire when: the dashboard stops using `ThreadingHTTPServer`._
- **[2026-09-24] The eval suite wrote to the developer's own `~/.env`** — `integrations._env_path()` is `dotenv.find_dotenv(usecwd=True)`, which walks UP from the cwd until it finds a `.env`. pytest's `tmp_path` sits under the user's temp directory, so six tests that chdir'd somewhere they believed was throwaway still resolved to `C:\Users\<name>\.env` and wrote there; the stray `WAKU_APPLE_*` keys in a real home directory came from exactly that. `evals/conftest.py` now redirects `_env_path` to `tmp_path/.env` for every test, which is also why `test_provider_disabled` stopped "failing on Windows" — it was never a Windows problem. _Retire when: `_env_path` takes its path as an argument._
